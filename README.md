# 🏥 Clínica Fisio

> Sistema web de agendamento e gerenciamento para clínica de fisioterapia.

---

## 📋 Sobre o Projeto

O **Clínica Fisio** é um sistema web desenvolvido para auxiliar no gerenciamento de uma clínica de fisioterapia, facilitando o controle de pacientes, consultas, avaliações físicas e pagamentos.

O sistema possui uma área destinada aos **pacientes** e outra área destinada à **administração da clínica**, permitindo centralizar as principais informações e tornar o gerenciamento dos atendimentos mais simples e organizado.

---

## ✨ Funcionalidades

### 👤 Área do Paciente

- 🔐 Login e acesso ao sistema
- 📅 Agendamento de consultas
- 🗓️ Visualização de consultas
- 📋 Histórico de atendimentos
- 🩺 Visualização da avaliação física
- 📝 Visualização de observações da profissional
- 📸 Acompanhamento da evolução através de fotos
- 💰 Visualização de informações sobre pagamentos

### 🔑 Área Administrativa

- 📊 Dashboard administrativo
- 👥 Gerenciamento de pacientes
- 📅 Gerenciamento de consultas
- 🗓️ Controle de agendamentos
- 🩺 Registro de avaliações físicas
- 📝 Registro de observações dos pacientes
- 📸 Registro de fotos de acompanhamento
- 💰 Controle e gestão de pagamentos
- 📈 Acompanhamento financeiro

🎯 Objetivo

O objetivo do projeto é oferecer uma solução digital para auxiliar uma clínica de fisioterapia no gerenciamento de seus atendimentos.

A plataforma permite organizar informações de pacientes, consultas, avaliações físicas e pagamentos em um único sistema.

O projeto também tem como objetivo aplicar conhecimentos de desenvolvimento web, lógica de programação, organização de projetos e controle de versão com Git e GitHub.
